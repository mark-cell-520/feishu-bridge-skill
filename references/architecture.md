# 架构说明

## 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                     飞书用户                                   │
└───────────────────────────┬─────────────────────────────────┘
                            │ 发送消息
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  飞书官方 WebSocket 长连接                                    │
│  - im.message.receive_v1 事件                                │
│  - 自动重连机制                                              │
└───────────────────────────┬─────────────────────────────────┘
                            │ 接收消息
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  feishu-bridge (Python)                                     │
│  - 消息标准化                                                │
│  - 用户白名单验证                                            │
│  - 消息去重                                                  │
└───────────────────────────┬─────────────────────────────────┘
                            │ 子进程调用
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  Claude Code 子进程                                          │
│  --mcp-config .claude/.mcp.json                              │
│  --settings bridge-settings.json                             │
└───────────────────────────┬─────────────────────────────────┘
                            │ MCP 工具调用
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  HeartFlow 心虫判别引擎 (MCP stdio)                          │
│  - checkInput: 用户消息门禁                                  │
│  - checkOutput: AI 回复监督                                  │
│  - 47 维判别                                                │
└───────────────────────────┬─────────────────────────────────┘
                            │ 判别结果
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  Claude Code 处理                                            │
│  - 调用 MCP 工具 (web-search / heartflow 等)                 │
│  - 生成回复                                                  │
└───────────────────────────┬─────────────────────────────────┘
                            │ 回复
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  飞书 API 发送回复                                           │
│  - 文本消息                                                  │
│  - 卡片消息                                                  │
└─────────────────────────────────────────────────────────────┘
```

## 核心组件

### 1. 飞书 WebSocket 连接

- 使用飞书官方 SDK `lark-oapi`
- 长连接模式（非 webhook）
- 自动重连 + 心跳保持

### 2. 消息处理流水线

```
接收 → 去重 → 标准化 → 白名单验证 → 子进程调用 → 回复发送
```

### 3. HeartFlow 集成

通过 MCP stdio 模式集成，提供输入/输出双门禁：

```json
{
  "mcpServers": {
    "heartflow": {
      "command": "node",
      "args": ["/path/to/mcp-server-stdio.js"]
    }
  }
}
```

### 4. MCP 工具扩展

桥接工作区支持额外 MCP 工具：
- `web-search` — Bing 搜索
- `heartflow` — 心虫判别
- 其他工具可按需添加

## 进程结构

```
父进程: feishu-bridge (Python, PID 25323)
  └─ 子进程: claude (Claude Code, PID 49314)
      └─ MCP: heartflow (Node, stdio)
      └─ MCP: web-search (Python, stdio)
```
